Transactional email

Send automatic emails from your app: welcome messages, login codes, receipts and alerts. One request, one API key, no mail server to run.

REST API Key + secret auth HTML or plain text Up to 5 recipients 20 emails/day free Usage limits per account
POST/api/email

How it works

  1. Create an API key on the APIs page.
  2. Send a POST request with your key and secret in the headers.
  3. Pick an email type, or send your own subject and message.
  4. The email is delivered and counted against your daily limit.
curl -X POST https://multibundle.vercel.app/api/email \ -H "x-api-key: YOUR_KEY" \ -H "x-api-secret: YOUR_SECRET" \ -H "Content-Type: application/json" \ -d '{"to":"user@mail.com","subject":"Hello","html":"<p>Hi!</p>"}'
